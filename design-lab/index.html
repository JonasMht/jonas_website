Design Lab

Three complete visual directions for the jonasx.xyz rework — each with landing, professional hub and personal hub, built with real content. The current implemented design (steel-blue card deck) remains on the branch as baseline. Pick one; it gets the full Hugo implementation.

Option A

Console

Dark terminal aesthetic. Monospace everywhere, CRT scanlines, a shell prompt that "lists" your two worlds, career as a git log, personal projects as a game launcher. Developer-brain, memorable, unapologetically nerdy.

Option B

Journal

Editorial print aesthetic. Cream paper, serif typography, double rules, oxblood accents. Landing reads as a magazine table of contents with two chapters; the CV is typeset like a serious publication; projects hang as framed plates. Distinctive, cultured, timeless.

Option C

Grid

Swiss brutalist aesthetic. Stark paper, giant grotesk type, International Klein Blue, exposed 2px grid lines, zero rounded corners. Landing is a numbered index that inverts on hover; research is a spec sheet; projects hang as a poster wall. Bold, confident, unmistakable.
