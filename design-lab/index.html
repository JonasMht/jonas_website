Design Lab — 9 directions

Nine complete visual directions for jonasx.xyz, each with landing / professional / personal pages, built with real content, shown desktop + phone. The current steel-blue implementation stays as baseline (V1, already on this branch). Click any design to open its live mockup.

Option D

Thermal

Born from the research itself. Heat-map gradients, isotherm rings, breathing thermal bloom, scan-line marquee. The identity no template can fake — it looks like the science.

Inspired by: medical-viz dashboards, dark scientific UI (Linear/Chartier).

Option E

arXiv

The website IS a research paper. Title block, abstract, numbered sections, results table, bibliography with [pdf][doi] links — and the personal side lives in "Appendix B". Unforgettable for academics; the pro page writes itself.

Inspired by: arXiv itself, Distill.pub, al-folio, "reads like a paper" portfolios.

Option F

Bento

Dashboard grid, app-like. Big Pro/Personal tiles among live "Now", "Latest paper", toolkit and social cards. The most mobile-native of all — it IS a phone screen stretched to desktop. Friendly, current, endlessly remixable.

Inspired by: bento.me, Traf, Bento Grids gallery, personal dashboards.

Option G

Kinetic

Oversized type, marquee energy. Outlined display name, acid-orange accents, doors that invert on hover, publications as "case studies", projects as filmstrip rows. The most designer-grade, awwwards-flavored option.

Inspired by: awwwards portfolios, brutalist-editorial studios, GIF-style marquees.

Option H

Blueprint

Engineering drawing sheets. Grid paper, title blocks, detail views, bills of research, part numbers, approval stamp. Speaks fluent med-tech engineering; nothing else on the internet looks like this.

Inspired by: technical drawings, NASA docs, Dieter Rams-spec sheets.
