What the critics broke — and what survived.

Three independent critics (design-adversarial, audience-conversion, Hugo-engineering) attacked the Station OS plan. Consensus hits were accepted as plan deltas; everything else survived. The plan is stronger for it — smaller where it was fat, armored where it was exposed.

Design · adversarial12 findings
Boot preloader = LCP woundHIGH

2s splash delays first paint; consensus 3/3 critics → demote.

Toy sim mistaken for researchHIGH

Clinicians will assume the hero is the validated tool → honesty caption + paper link.

Motion = vestibular hazardHIGH

~35% of adults 40+ have vestibular dysfunction → reduced-motion designed FIRST, as a peer theme.

Canvas invisible to crawlers/no-JSHIGH

Hero copy must live in HTML; sim is enhancement only.

Site becomes about the siteMED

5 layers of self-referential chrome → v1 ships exactly ONE signature interaction.

Dark-only + coined termMED

Light theme via prefers-color-scheme; coin stays voice, nav keeps searchable terms.

Audience · conversion12 gaps

No Scholar profile; ORCID orphaned on one paper → 5-icon verification row + contact CTA.

CV PDF missingHIGH

Hospital/corporate machines → 30s MP4 fallback layer.

C-NCA paper is closed-accessMED

Springer LNCS allows author deposit → HAL self-archive, OA badge on cards.

No "how to cite me"MED

Engineering · Hugo reality14 findings
Boot: ≤300ms, sessionStorage, or cutHIGH

noscript would trap visitors on a static splash → JS-gated fade only.

Firefox gapMED

No cross-doc VT; scroll-driven still preview → IO as universal path, VT purely additive.

/lab is four projects in a trenchcoatHIGH

Slider S · plots M · sandbox L · game M → split into 4 tickets, slider ships first.

Freeze the front-matter schemaMED

One field rename later = sed across the whole tree → freeze before content batch.

Zero-JS core is the load-bearing wallHIGH

Everything JS adds must degrade; verify with disable-JS audit + CI screenshots.

i18n FR/EN = ongoing LLOW

Defer; externalize strings from day one so it stays addable.

Plan deltas — accepted into v2

  • 02 boot demoted: 2s sequence → ≤300ms "ignition blink", JS-only, once/session, reduced-motion skip
  • 01 hero re-architected: static thermal poster is the LCP element; sim = idle enhancement; tap-to-place on touch
  • Honesty guard: hero carries "toy model — validated pipeline in the papers" caption + [VIDEO] fallback
  • Theme contract: light "clinical" theme + reduced-motion mode designed as first-class peers, not ports
  • Scope guillotine: v1 = one signature interaction; achievements + konami deferred, reworded as lab-notebook lore
  • New credibility layer: CV PDF · identity block · HAL · cite/BibTeX · defense timeline · legal · SEO pack
