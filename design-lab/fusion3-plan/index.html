The Thermal LUT — one gradient to rule the system

The planner hero, the image lens and the HUD all sample the same lookup table: deep slate → steel → white-hot. Promote it to a design token and every "hot" surface in the site speaks the same thermal language — meaning gradients appear only where heat is semantically true.
