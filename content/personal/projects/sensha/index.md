## Project

Sensha is a 2D real-time strategy game I developed in Python and PyGame for the Informatique et Sciences du Numérique option of the 2019 Baccalauréat.

Players manage resources and deploy tanks against an AI opponent. I developed the game and its original 2D sprites, taking the project from an initial concept to a playable program.

[Source code on GitHub](https://github.com/JonasMht/Sensha-Game-2019)
