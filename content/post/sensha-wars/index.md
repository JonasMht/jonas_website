## Description
Sensha Wars is an upcoming 2D strategy game and successor to Sensha. It is being developed using the Godot engine and there is no official release date announced yet. As the only developer on this passion project, I am responsible for creating the assets, interfaces and writing code. This project has been an excellent opportunity for me to improve my programming skills and gain valuable experience in game development. The gameplay of Sensha Wars will retain the essence of Sensha and be centered around the player making strategic decisions. The game will feature different types of modular units, maps, and objectives, providing players with a unique and engaging experience. Stay tuned for more updates on the development of Sensha Wars!
