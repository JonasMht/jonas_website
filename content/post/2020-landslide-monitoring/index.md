## Description
During the summer of 2020 I did an internship at EOST, Strasbourg, during which I developed a data-analysis tool using Python and the Matplotlib library. This tool analyses data that was sampled on landslide regions and generates statistics and graphs that facilitate the surveillance of these areas.
